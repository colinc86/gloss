## Keyboard shortcuts

Help › Keyboard Shortcuts (⌘/) shows them all in the app. The ones you'll use most:

| Shortcut | Does |
| --- | --- |
| ⌘P | Open Quickly: find any file under the open folder |
| ⇧⌘O | Open Folder… |
| ⌘↩ | Add a note while text is selected; otherwise send the document's drafts |
| ⇧⌘N | New note from the selection, or on the whole file |
| ⇧⌘↩ | Send all drafts, across documents |
| ⇧⌘C | Copy the document's drafts as a packet |
| ⌘' / ⇧⌘' | Next / previous note |
| ⇧⌘D | Resolve the selected note |
| ⌥⌘N | Show or hide the notes panel |
| ⇧⌘M | Toggle Markdown between rendered and source |
| ⇧⌘F | Find in files |
| ⌥⌘J | Filter the file tree |
| ⇧⌘J | Reveal the open document in the tree |
| ⌘L | Go to line |
| ⇧⌘L | Open Location… (a web page or dev server) |
| ⌥⌘P | Open Pull Request… |
| ⌥⌘I | Open Jira Issue or Confluence Page… |
| ⌥⌘↓ / ⌥⌘↑ | Next / previous change in a pull request file |
| ⌃⌘← / ⌃⌘→ | Back / forward through the documents you've shown |
